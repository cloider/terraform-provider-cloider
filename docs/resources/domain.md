# Resource: cloider_domain

Manages a domain: either a free subdomain under one of Cloider's roots, such as `my-app.cloider.app`,
or a domain you own. A name under one of the roots in
[`cloider_options`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/data-sources/options)'
`subdomain_roots` is claimed as a free subdomain, any other name is added as a custom domain.

A custom domain is served by Cloider's DNS once its registrar points it at the `nameservers` in
`cloider_options`. Add its records with
[`cloider_dns_record`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/dns_record).

!> **Warning:** Deleting a domain also deletes its DNS records and the routes to it.

## Example Usage

### Free Subdomain

```terraform
# A free subdomain under one of Cloider's roots
resource "cloider_domain" "app" {
  name = "acme.cloider.app"
}
```

### Subdomain of the First Root Offered

```terraform
# The subdomain roots are what cloider_options offers
data "cloider_options" "current" {}

resource "cloider_domain" "preview" {
  name = "acme-preview.${data.cloider_options.current.subdomain_roots[0]}"
}
```

### Custom Domain

```terraform
# A domain you own. Point it at these nameservers at its registrar.
resource "cloider_domain" "example" {
  name = "example.com"
}

data "cloider_options" "current" {}

output "nameservers" {
  value = data.cloider_options.current.nameservers
}
```

### Custom Domain with Records

```terraform
resource "cloider_domain" "example" {
  name = "example.com"
}

resource "cloider_dns_record" "www" {
  domain = cloider_domain.example.name
  type   = "CNAME"
  name   = "www"
  values = ["example.com."]
  ttl    = 3600
}
```

## Schema

### Required

- `name` (String) The domain name, lower case and without a trailing dot. A name under one of `cloider_options`' `subdomain_roots` is claimed as a free subdomain, anything else is added as a custom domain. Changing it replaces the domain.

### Read-Only

- `created_at` (String) When the domain was added, RFC 3339.
- `id` (String) The domain name.
- `status` (String) `Pending` until something routes to it, `Active` while something does, `Suspended` once nothing does any more.
- `type` (String) `Subdomain` or `CustomDomain`.

## Import

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import)
to import a domain by its name:

```terraform
import {
  to = cloider_domain.example
  id = "example.com"
}
```

Using [`terraform import`](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# A domain is imported by its name
terraform import cloider_domain.example example.com
```
