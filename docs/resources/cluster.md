# Resource: cloider_cluster

Manages a Kubernetes cluster. Creating one waits until it is `Ready`, and its `kube_config` then holds
what the [`kubernetes`](https://registry.terraform.io/providers/hashicorp/kubernetes/latest/docs) and
[`helm`](https://registry.terraform.io/providers/hashicorp/helm/latest/docs) providers need to deploy
into it.

~> **Note:** A cluster can't be renamed or upgraded in place, so changing `name` or `version`
replaces the cluster and everything running in it.

-> **Note:** Ingress objects in the cluster aren't served. To reach a Service from the internet, route
a domain to it with a [`cloider_target`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/target).
To deploy into an existing cluster from another configuration, look it up with the
[`cloider_cluster`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/data-sources/cluster)
data source.

## Example Usage

### Basic Usage

```terraform
resource "cloider_cluster" "web" {
  name = "web"
}
```

### Deploying with the Kubernetes Provider

The client certificate authenticates as the cluster's admin. See the
[Kubernetes and Helm guide](https://registry.terraform.io/providers/cloider/cloider/latest/docs/guides/kubernetes-and-helm)
for a whole app, and for when to keep the cluster and what runs in it in separate configurations.

```terraform
resource "cloider_cluster" "web" {
  name = "web"
}

provider "kubernetes" {
  host                   = cloider_cluster.web.kube_config.host
  cluster_ca_certificate = cloider_cluster.web.kube_config.cluster_ca_certificate
  client_certificate     = cloider_cluster.web.kube_config.client_certificate
  client_key             = cloider_cluster.web.kube_config.client_key
}

resource "kubernetes_namespace_v1" "shop" {
  metadata {
    name = "shop"
  }
}
```

### Installing a Helm Chart

```terraform
resource "cloider_cluster" "web" {
  name = "web"
}

# The helm provider 3.x takes kubernetes as an attribute
provider "helm" {
  kubernetes = {
    host                   = cloider_cluster.web.kube_config.host
    cluster_ca_certificate = cloider_cluster.web.kube_config.cluster_ca_certificate
    client_certificate     = cloider_cluster.web.kube_config.client_certificate
    client_key             = cloider_cluster.web.kube_config.client_key
  }
}

resource "helm_release" "podinfo" {
  name             = "podinfo"
  repository       = "https://stefanprodan.github.io/podinfo"
  chart            = "podinfo"
  namespace        = "podinfo"
  create_namespace = true
}
```

### Writing a Kubeconfig File

With the [`local`](https://registry.terraform.io/providers/hashicorp/local/latest/docs) provider:

```terraform
resource "cloider_cluster" "web" {
  name = "web"
}

# For kubectl: KUBECONFIG=./kubeconfig-web.yaml kubectl get pods -A
resource "local_sensitive_file" "kubeconfig" {
  filename        = "${path.module}/kubeconfig-web.yaml"
  content         = cloider_cluster.web.kube_config.raw
  file_permission = "0600"
}
```

### Pausing a Cluster

```terraform
variable "staging_paused" {
  description = "Pauses the staging cluster, which keeps its state and isn't billed for compute."
  type        = bool
  default     = false
}

resource "cloider_cluster" "staging" {
  name   = "staging"
  paused = var.staging_paused
}
```

### Choosing the Kubernetes Version

```terraform
data "cloider_options" "current" {}

# A cluster isn't upgraded in place: a new version replaces it. Ignoring
# changes keeps the version it was created with.
resource "cloider_cluster" "web" {
  name    = "web"
  version = data.cloider_options.current.cluster_versions[0]

  lifecycle {
    ignore_changes = [version]
  }
}
```

### Timeouts

```terraform
resource "cloider_cluster" "web" {
  name = "web"

  timeouts = {
    create = "30m"
    delete = "30m"
  }
}
```

## Schema

### Required

- `name` (String) The cluster's name: lower case letters, digits and `-`, starting with a letter. Names don't have to be unique, the dashboard tells clusters of the same name apart by `label`.

### Optional

- `paused` (Boolean) Whether the cluster is paused. A paused cluster keeps its state and isn't billed for compute. Defaults to `false`.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))
- `version` (String) The Kubernetes version, one of `cloider_options`' `cluster_versions`. Defaults to the newest offered.

### Read-Only

- `created_at` (String) When the cluster was created, RFC 3339.
- `id` (String) The cluster's id.
- `kube_config` (Attributes, Sensitive) How to reach the cluster's Kubernetes api, for the `kubernetes` and `helm` providers. (see [below for nested schema](#nestedatt--kube_config))
- `label` (String) The name the dashboard shows, `name` with a `-1`, `-2`... suffix when another cluster has it.
- `status` (String) `Creating`, `Starting`, `Ready`, `Pausing`, `Paused` or `Terminating`.

### Nested Schema for `kube_config`

Read-Only:

- `client_certificate` (String, Sensitive) The PEM client certificate to authenticate with.

## Timeouts

[Configuration options](https://developer.hashicorp.com/terraform/language/resources/syntax#operation-timeouts):

* `create` - (Default `20m`) Waiting for the cluster to be `Ready`.
* `update` - (Default `20m`) Waiting for a pause or resume.
* `delete` - (Default `20m`)

## Import

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import)
to import a cluster by its id. `cloider cluster list -o wide` shows the ids:

```terraform
import {
  to = cloider_cluster.web
  id = "x8f2kq"
}
```

Using [`terraform import`](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# A cluster is imported by its id, see `cloider cluster list -o wide`
terraform import cloider_cluster.web x8f2kq
```
