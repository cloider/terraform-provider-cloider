# Resource: cloider_bucket

Manages an S3 compatible object storage bucket. Any S3 client or SDK reaches it at its `endpoint`, in
its `region`, with a
[`cloider_bucket_key`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/bucket_key).
See [Using Buckets with S3 Tools](https://registry.terraform.io/providers/cloider/cloider/latest/docs/guides/object-storage)
for the AWS CLI, rclone and the AWS provider.

-> **Note:** Bucket names are shared by every Cloider account, so a name has to be one nobody else
has. Changing `name` or `region` replaces the bucket.

## Example Usage

### Private Bucket

```terraform
# Private: every request needs a cloider_bucket_key
resource "cloider_bucket" "uploads" {
  name = "acme-uploads"
}
```

### Public Bucket

```terraform
# Anyone may download a file with its link, without a key. Listing the
# bucket and changing files still need one.
resource "cloider_bucket" "assets" {
  name   = "acme-assets"
  public = true
}

# A file is read at <url>/<key>, such as .../logo.png
output "assets_url" {
  value = cloider_bucket.assets.url
}
```

### Versioning

```terraform
# Keeps the previous versions of overwritten and deleted files
resource "cloider_bucket" "backups" {
  name       = "acme-backups"
  versioning = true
}
```

### Static Website

Serve it on a domain of your own with a
[`cloider_target`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/target)
and `bucket_id`.

```terraform
# Served as a static website at website_url: / and every path ending in a
# slash get index.html, anything missing gets 404.html with a 404. The website
# is read without a key, so the bucket has to be public.
resource "cloider_bucket" "site" {
  name           = "acme-site"
  public         = true
  website        = true
  index_document = "index.html"
  error_document = "404.html"
}

output "site_url" {
  value = cloider_bucket.site.website_url
}
```

### CORS Rules

The Cloider dashboard keeps working whatever the rules say, and the first rule whose origin matches
answers a preflight.

```terraform
# Only these websites can use the bucket from a browser: the app uploads with
# presigned URLs and reads the ETag of each part, and the marketing site reads
# files. Without cors_rule blocks any website can.
resource "cloider_bucket" "uploads" {
  name = "acme-uploads"

  cors_rule {
    id              = "web-app"
    allowed_origins = ["https://app.acme.com"]
    allowed_methods = ["GET", "PUT", "POST"]
    allowed_headers = ["*"]
    expose_headers  = ["ETag"]
    max_age_seconds = 3000
  }

  cors_rule {
    allowed_origins = ["https://*.acme.com"]
    allowed_methods = ["GET", "HEAD"]
  }
}
```

### Bucket with an Access Key

```terraform
resource "cloider_bucket" "uploads" {
  name = "acme-uploads"
}

resource "cloider_bucket_key" "app" {
  label   = "app"
  buckets = [cloider_bucket.uploads.id]
}

# The settings any S3 client takes
output "s3_environment" {
  value = {
    AWS_ACCESS_KEY_ID   = cloider_bucket_key.app.access_key
    AWS_REGION          = cloider_bucket.uploads.region
    AWS_ENDPOINT_URL_S3 = cloider_bucket.uploads.endpoint
    S3_BUCKET           = cloider_bucket.uploads.name
  }
}
```

### Region

The regions, with their endpoints, are listed by
[`cloider_bucket_regions`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/data-sources/bucket_regions).

```terraform
resource "cloider_bucket" "assets" {
  name   = "acme-assets"
  region = "eu-central-2"
}
```

### One Bucket per Environment

```terraform
variable "environments" {
  type    = set(string)
  default = ["staging", "production"]
}

resource "cloider_bucket" "uploads" {
  for_each = var.environments

  name       = "acme-uploads-${each.key}"
  versioning = each.key == "production"
}
```

## Schema

### Required

- `name` (String) The bucket's name, 3 to 63 lower case letters, digits and `-`. Bucket names are shared by every Cloider account, so it has to be one nobody else has. Changing it replaces the bucket.

### Optional

- `cors_rule` (Block List) The websites that can use the bucket from a browser. Without `cors_rule` blocks any website can. With them only the origins they list can, and the Cloider dashboard always can. The first rule whose origin matches answers a preflight. (see [below for nested schema](#nestedblock--cors_rule))
- `error_document` (String) The key the website serves, with a 404, for anything missing. Defaults to `""`, a built-in page.
- `index_document` (String) The file the website serves for a path ending in a slash, a name without a slash. Defaults to `index.html`.
- `public` (Boolean) Whether anyone may read the bucket's files without a key. Defaults to `false`.
- `region` (String) The region code, see `cloider_bucket_regions`. Defaults to the first region. Changing it replaces the bucket.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))
- `versioning` (Boolean) Whether the bucket keeps previous versions of its files. Versioning that was on can only be suspended, so `false` after `true` keeps the versions already kept. Defaults to `false`.
- `website` (Boolean) Whether the bucket is served as a static website at `website_url`, and on the domains a `cloider_target` with `bucket_id` routes to it. The website is read without a key, so it needs `public`. Defaults to `false`.

### Read-Only

- `created_at` (String) When the bucket was created, RFC 3339.
- `endpoint` (String) The S3 endpoint of the bucket's region.
- `id` (String) The bucket's id.
- `status` (String) `Ready`, `Failed` or `Terminating`.
- `url` (String) The bucket's url, where a public bucket's files are read.
- `website_url` (String) The website's own address, `https://<name>.s3-website.<region>.<domain>`, while `website` is on.

<a id="nestedblock--cors_rule"></a>
### Nested Schema for `cors_rule`

Required:

- `allowed_methods` (List of String) Any of `GET`, `HEAD`, `PUT`, `POST` and `DELETE`.
- `allowed_origins` (List of String) Origins as browsers send them, in lower case and without a path, like `https://app.example.com`. `https://*.example.com` matches its subdomains, `*` any website.

Optional:

- `allowed_headers` (List of String) Request headers a page may send, like `Content-Type`. `*` for any, or a prefix like `x-amz-*`.
- `expose_headers` (List of String) Response headers a page's script can read, like `ETag`.
- `id` (String) A name for the rule.
- `max_age_seconds` (Number) How long browsers may reuse a preflight answer, 1 to 86400. Leave it out for their default.

## Import

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import)
to import a bucket by its id. `cloider bucket list -o wide` shows the ids:

```terraform
import {
  to = cloider_bucket.assets
  id = "b7r2xw"
}
```

Using [`terraform import`](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# A bucket is imported by its id, see `cloider bucket list -o wide`
terraform import cloider_bucket.assets b7r2xw
```
