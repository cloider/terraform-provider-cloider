# Resource: cloider_registry_token

Manages a token to push and pull the images of some or all of your
[`cloider_registry`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/registry)
projects, used as `docker login <host> -u <username> -p <secret>`.

~> **Note:** The secret is only shown when the token is created. Terraform keeps it in state, so treat
the state as sensitive. An imported token has no `secret`.

## Example Usage

### Push Token for CI

```terraform
resource "cloider_registry" "images" {
  name = "acme"
}

resource "cloider_registry_token" "ci" {
  label           = "CI push"
  projects        = [cloider_registry.images.id]
  expires_in_days = 365
}

# docker login <host> -u <username> -p <secret>
output "registry_login" {
  value = {
    host     = cloider_registry.images.host
    username = cloider_registry_token.ci.username
  }
}

output "registry_password" {
  value     = cloider_registry_token.ci.secret
  sensitive = true
}
```

### Image Pull Secret for a Cluster

A read-only token, handed to a Cloider cluster as an image pull secret with the
[`kubernetes`](https://registry.terraform.io/providers/hashicorp/kubernetes/latest/docs) provider.

```terraform
resource "cloider_registry_token" "pull" {
  label     = "web cluster pull"
  projects  = [cloider_registry.images.id]
  read_only = true
}

# An image pull secret for the kubernetes provider, see the cloider_cluster docs
resource "kubernetes_secret_v1" "registry" {
  metadata {
    name      = "cloider-registry"
    namespace = "default"
  }

  type = "kubernetes.io/dockerconfigjson"

  data = {
    ".dockerconfigjson" = jsonencode({
      auths = {
        (cloider_registry.images.host) = {
          username = cloider_registry_token.pull.username
          password = cloider_registry_token.pull.secret
          auth     = base64encode("${cloider_registry_token.pull.username}:${cloider_registry_token.pull.secret}")
        }
      }
    })
  }
}
```

### Every Project

```terraform
# Reaches every project, those created later included
resource "cloider_registry_token" "mirror" {
  label        = "Backup mirror"
  all_projects = true
  read_only    = true
}
```

### Rotating a Token

With the [`time`](https://registry.terraform.io/providers/hashicorp/time/latest/docs) provider's
`time_rotating`:

```terraform
# Replaces the token every 90 days, a month before it would expire. The new
# token is created before the old one is deleted.
resource "time_rotating" "ci" {
  rotation_days = 90
}

resource "cloider_registry_token" "ci" {
  label           = "CI push"
  projects        = [cloider_registry.images.id]
  expires_in_days = 120

  lifecycle {
    create_before_destroy = true
    replace_triggered_by  = [time_rotating.ci]
  }
}
```

### Storing the Token in GitHub Actions

```terraform
# Hands the token to a GitHub Actions workflow with the integrations/github provider
resource "github_actions_secret" "registry_username" {
  repository      = "web"
  secret_name     = "CLOIDER_REGISTRY_USERNAME"
  plaintext_value = cloider_registry_token.ci.username
}

resource "github_actions_secret" "registry_password" {
  repository      = "web"
  secret_name     = "CLOIDER_REGISTRY_PASSWORD"
  plaintext_value = cloider_registry_token.ci.secret
}
```

## Schema

### Required

- `label` (String) What the token is for.

### Optional

- `all_projects` (Boolean) Whether the token reaches every project, those made later included. Set this or `projects`. Defaults to `false`.
- `expires_in_days` (Number) Days until the token stops working, 1 to 3650, or `0` for never. Expiry can't be changed, so changing it replaces the token. Defaults to `0`.
- `projects` (Set of String) The ids of the `cloider_registry` projects the token reaches. Set this or `all_projects`.
- `read_only` (Boolean) Whether the token may only pull. Defaults to `false`.

### Read-Only

- `created_at` (String) When the token was created, RFC 3339.
- `expires_at` (String) When the token stops working, RFC 3339, null for never.
- `id` (String) The token's id.
- `secret` (String, Sensitive) The password to log in with. Only known for a token this configuration created.
- `username` (String) The username to log in with.

## Import

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import)
to import a token by its id. `cloider registry token list -o wide` shows the ids:

```terraform
import {
  to = cloider_registry_token.ci
  id = "t9w1qe"
}
```

Using [`terraform import`](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# A token is imported by its id, see `cloider registry token list -o wide`.
# Its secret was only shown when it was created, so it stays unknown.
terraform import cloider_registry_token.ci t9w1qe
```
