# Resource: cloider_registry

Manages a container registry project, where images are pushed to and pulled from as
`<url>/<repository>:<tag>`. Push and pull private images with a
[`cloider_registry_token`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/registry_token).

-> **Note:** Project names are shared by every Cloider account, so a name has to be one nobody else
has. Changing `name` replaces the project, and its images with it.

## Example Usage

### Basic Usage

```terraform
resource "cloider_registry" "images" {
  name = "acme"
}

# Push as <url>/<repository>:<tag>, such as acme/web:1.4.0
output "image_prefix" {
  value = cloider_registry.images.url
}
```

### Immutable Tags

```terraform
# Tags can't be pushed over or deleted, so a deployed tag always means the same image
resource "cloider_registry" "releases" {
  name             = "acme-releases"
  storage_limit_gi = 20
  immutable_tags   = true
}
```

### Public Project

```terraform
# Anyone may pull without a token, pushing still needs one
resource "cloider_registry" "oss" {
  name   = "acme-oss"
  public = true
}
```

## Schema

### Required

- `name` (String) The project's name, 3 to 63 lower case letters, digits and `-`. Project names are shared by every Cloider account, so it has to be one nobody else has. Changing it replaces the project and its images.

### Optional

- `immutable_tags` (Boolean) Whether pushing over a tag or deleting one is refused, `latest` included. Defaults to `false`.
- `public` (Boolean) Whether anyone may pull its images without a token. Pushing always needs one. Defaults to `false`.
- `storage_limit_gi` (Number) The most GiB its images may take, 1 to 20. A push past it is refused. Defaults to `5`.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `created_at` (String) When the project was created, RFC 3339.
- `host` (String) The registry host to `docker login` to.
- `id` (String) The project's id.
- `status` (String) `Ready`, `Failed` or `Terminating`.
- `url` (String) The prefix of every image in the project, `<host>/<name>`.

## Import

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import)
to import a project by its id. `cloider registry list -o wide` shows the ids:

```terraform
import {
  to = cloider_registry.images
  id = "r4t6yu"
}
```

Using [`terraform import`](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# A project is imported by its id, see `cloider registry list -o wide`
terraform import cloider_registry.images r4t6yu
```
