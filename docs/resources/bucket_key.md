# Resource: cloider_bucket_key

Manages an S3 access key for some or all of your
[`cloider_bucket`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/bucket)s.
Any S3 client takes it as `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`, with the bucket's
`endpoint`.

~> **Note:** The secret key is only shown when the key is created. Terraform keeps it in state, so
treat the state as sensitive. An imported key has no `secret_key`.

## Example Usage

### Key for One Bucket

```terraform
resource "cloider_bucket" "assets" {
  name = "acme-assets"
}

# Reads and writes one bucket
resource "cloider_bucket_key" "deploy" {
  label   = "CI deploy"
  buckets = [cloider_bucket.assets.id]
}
```

### Read-Only Key for Every Bucket

```terraform
# Reads every bucket, those created later included
resource "cloider_bucket_key" "backup_reader" {
  label       = "Backup reader"
  all_buckets = true
  read_only   = true
}
```

### Passing the Key to a Kubernetes Workload

```terraform
# The key as environment variables for a workload in a Cloider cluster,
# with the kubernetes provider configured as in the cloider_cluster docs
resource "kubernetes_secret_v1" "s3" {
  metadata {
    name      = "s3"
    namespace = "default"
  }

  data = {
    AWS_ACCESS_KEY_ID     = cloider_bucket_key.deploy.access_key
    AWS_SECRET_ACCESS_KEY = cloider_bucket_key.deploy.secret_key
    AWS_REGION            = cloider_bucket.assets.region
    AWS_ENDPOINT_URL_S3   = cloider_bucket.assets.endpoint
    S3_BUCKET             = cloider_bucket.assets.name
  }
}
```

### Outputs for an S3 Client

```terraform
output "s3_endpoint" {
  value = cloider_bucket.assets.endpoint
}

output "s3_access_key" {
  value = cloider_bucket_key.deploy.access_key
}

# terraform output -raw s3_secret_key
output "s3_secret_key" {
  value     = cloider_bucket_key.deploy.secret_key
  sensitive = true
}
```

## Schema

### Required

- `label` (String) What the key is for, up to 64 characters.

### Optional

- `all_buckets` (Boolean) Whether the key reaches every bucket, those made later included. Set this or `buckets`. Defaults to `false`.
- `buckets` (Set of String) The ids of the buckets the key reaches. Set this or `all_buckets`. A bucket that is deleted drops out of it.
- `read_only` (Boolean) Whether the key may only read. Defaults to `false`.

### Read-Only

- `access_key` (String) The access key id, `AWS_ACCESS_KEY_ID`.
- `created_at` (String) When the key was created, RFC 3339.
- `id` (String) The key's id.
- `secret_key` (String, Sensitive) The secret access key, `AWS_SECRET_ACCESS_KEY`. Only known for a key this configuration created.

## Import

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import)
to import a key by its id. `cloider bucket key list -o wide` shows the ids:

```terraform
import {
  to = cloider_bucket_key.deploy
  id = "k3m8vd"
}
```

Using [`terraform import`](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# A key is imported by its id, see `cloider bucket key list -o wide`. Its
# secret key was only shown when it was created, so it stays unknown.
terraform import cloider_bucket_key.deploy k3m8vd
```
