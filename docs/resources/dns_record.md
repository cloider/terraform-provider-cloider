# Resource: cloider_dns_record

Manages a DNS record set of a custom [`cloider_domain`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/domain):
every value of one type at one name. Cloider keeps one record per type and name, so list all of a
name's values in one resource rather than one resource per value.

-> **Note:** Only a domain you own takes records. The domain answers them once its registrar points
it at the nameservers in [`cloider_options`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/data-sources/options).
Free subdomains under Cloider's roots, such as `my-app.cloider.app`, don't take records.

## Example Usage

### Basic Usage

```terraform
resource "cloider_domain" "example" {
  name = "example.com"
}

resource "cloider_dns_record" "www" {
  domain = cloider_domain.example.name
  type   = "A"
  name   = "www"
  values = ["203.0.113.10", "203.0.113.11"]
  ttl    = 3600
}
```

### The Domain Itself

Leave `name` out for a record at the domain itself, often called the apex or `@`.

```terraform
# name left out is the domain itself, example.com
resource "cloider_dns_record" "apex" {
  domain = "example.com"
  type   = "A"
  values = ["203.0.113.10"]
  ttl    = 300
}

resource "cloider_dns_record" "apex_ipv6" {
  domain = "example.com"
  type   = "AAAA"
  values = ["2001:db8::10"]
  ttl    = 300
}
```

### CNAME Record

```terraform
# A CNAME takes one value, and no other record can share its name
resource "cloider_dns_record" "docs" {
  domain = "example.com"
  type   = "CNAME"
  name   = "docs"
  values = ["example.github.io."]
  ttl    = 3600
}
```

### Mail Records

MX values are a priority and a host. A host ending in a dot is a full name, as in a zone file.

```terraform
resource "cloider_dns_record" "mx" {
  domain = "example.com"
  type   = "MX"
  values = ["10 mx1.mail.example.net.", "20 mx2.mail.example.net."]
  ttl    = 3600
}

resource "cloider_dns_record" "spf" {
  domain = "example.com"
  type   = "TXT"
  values = ["v=spf1 include:mail.example.net ~all"]
  ttl    = 3600
}

resource "cloider_dns_record" "dmarc" {
  domain = "example.com"
  type   = "TXT"
  name   = "_dmarc"
  values = ["v=DMARC1; p=quarantine; rua=mailto:dmarc@example.com"]
  ttl    = 3600
}
```

### TXT Records

```terraform
# Each value is a TXT record of its own, so an SPF policy and verification
# tokens at the same name go in one resource
resource "cloider_dns_record" "apex_txt" {
  domain = "example.com"
  type   = "TXT"
  values = [
    "v=spf1 include:mail.example.net ~all",
    "google-site-verification=rXOxyZounnZasA8Z7oaD3c14JdjS9aKSWvsR1EbUSIQ",
  ]
  ttl = 3600
}

# A value over 255 characters, such as a DKIM key, is fine as one value
resource "cloider_dns_record" "dkim" {
  domain = "example.com"
  type   = "TXT"
  name   = "mail._domainkey"
  values = ["v=DKIM1; k=rsa; p=MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEAu5..."]
  ttl    = 3600
}
```

### CAA Record

```terraform
# Which certificate authorities may issue certificates for the domain. Cloider's
# certificates for a cloider_target come from Let's Encrypt, so keep it allowed.
resource "cloider_dns_record" "caa" {
  domain = "example.com"
  type   = "CAA"
  values = [
    "0 issue \"letsencrypt.org\"",
    "0 iodef \"mailto:security@example.com\"",
  ]
  ttl = 3600
}
```

### Wildcard Record

```terraform
# Answers for any name under example.com that has no record of its own
resource "cloider_dns_record" "wildcard" {
  domain = "example.com"
  type   = "A"
  name   = "*"
  values = ["203.0.113.10"]
  ttl    = 300
}
```

### SRV Record

```terraform
# priority weight port target
resource "cloider_dns_record" "sip" {
  domain = "example.com"
  type   = "SRV"
  name   = "_sip._tcp"
  values = ["10 60 5060 sip1.example.com.", "20 40 5060 sip2.example.com."]
  ttl    = 3600
}
```

### Many Records from a Map

```terraform
locals {
  records = {
    "www/A"        = { name = "www", type = "A", values = ["203.0.113.10"] }
    "api/A"        = { name = "api", type = "A", values = ["203.0.113.20", "203.0.113.21"] }
    "status/CNAME" = { name = "status", type = "CNAME", values = ["status.example.net."] }
  }
}

resource "cloider_dns_record" "this" {
  for_each = local.records

  domain = "example.com"
  name   = each.value.name
  type   = each.value.type
  values = each.value.values
  ttl    = 3600
}
```

## Schema

### Required

- `domain` (String) The custom domain the record belongs to. Subdomains under Cloider's roots don't take records. Changing it replaces the record.
- `ttl` (Number) Seconds resolvers may cache the record, 60 to 172800.
- `type` (String) `A`, `AAAA`, `CNAME`, `MX`, `TXT`, `NS`, `CAA`, `HTTPS`, `SPF`, `SRV`, `PTR`.
- `values` (List of String) The record's values, such as IP addresses for `A` or `10 mail.example.com.` for `MX`. Each `TXT` value is a TXT record of its own. A `CNAME` takes one.

### Optional

- `name` (String) The name under the domain, such as `www`. Defaults to `""`, the domain itself.

### Read-Only

- `id` (String) The record's id.

## Import

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import)
to import a DNS record by its id. `cloider dns list <domain>` shows the ids:

```terraform
import {
  to = cloider_dns_record.www
  id = "1042"
}
```

Using [`terraform import`](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# A record is imported by its id, see `cloider dns list example.com -o wide`
terraform import cloider_dns_record.www 1042
```
