# Data Source: cloider_options

Lists what can be created at the moment: the Kubernetes versions a
[`cloider_cluster`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/cluster)
can run, the engines, versions and plans of a
[`cloider_database`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/database),
the roots a free subdomain goes under, and the nameservers a custom domain points at.

## Example Usage

### Basic Usage

```terraform
data "cloider_options" "current" {}

output "kubernetes_versions" {
  value = data.cloider_options.current.cluster_versions
}
```

### Newest Kubernetes Version

```terraform
data "cloider_options" "current" {}

# A cluster isn't upgraded in place: a new version replaces it. Ignoring
# changes keeps the version it was created with.
resource "cloider_cluster" "web" {
  name    = "web"
  version = data.cloider_options.current.cluster_versions[0]

  lifecycle {
    ignore_changes = [version]
  }
}
```

### Newest Version of a Database Engine

```terraform
data "cloider_options" "current" {}

locals {
  postgresql_versions = one([
    for e in data.cloider_options.current.database_engines : e.versions if e.engine == "postgresql"
  ])
}

resource "cloider_database" "orders" {
  name    = "orders"
  engine  = "postgresql"
  version = local.postgresql_versions[0]

  lifecycle {
    ignore_changes = [version]
  }
}
```

### Checking a Variable Against What Is Offered

```terraform
data "cloider_options" "current" {}

variable "database_plan" {
  type    = string
  default = "starter"
}

resource "cloider_database" "orders" {
  name   = "orders"
  engine = "postgresql"
  plan   = var.database_plan

  lifecycle {
    precondition {
      condition     = contains(data.cloider_options.current.database_plans, var.database_plan)
      error_message = "database_plan has to be one of ${join(", ", data.cloider_options.current.database_plans)}."
    }
  }
}
```

## Schema

### Read-Only

- `cluster_versions` (List of String) The Kubernetes versions a `cloider_cluster` can run, newest first.
- `database_engines` (Attributes List) The engines a `cloider_database` can run. (see [below for nested schema](#nestedatt--database_engines))
- `database_plans` (List of String) The plans a `cloider_database` can have, smallest first.
- `nameservers` (List of String) The nameservers to point a custom `cloider_domain` at, at its registrar.
- `subdomain_roots` (List of String) The roots a free subdomain `cloider_domain` goes under, such as `cloider.app`.
