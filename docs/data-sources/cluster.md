# Data Source: cloider_cluster

Looks up an existing [`cloider_cluster`](https://registry.terraform.io/providers/cloider/cloider/latest/docs/resources/cluster)
by `id` or `name`, with the `kube_config` the
[`kubernetes`](https://registry.terraform.io/providers/hashicorp/kubernetes/latest/docs) and
[`helm`](https://registry.terraform.io/providers/hashicorp/helm/latest/docs) providers need. Use it to
deploy into a cluster from a configuration other than the one that created it, or into one created in
the dashboard.

-> **Note:** Cluster names don't have to be unique. A name several clusters have is refused, so look
those up by `id`.

## Example Usage

### Basic Usage

```terraform
data "cloider_cluster" "web" {
  name = "web"
}

output "web_cluster_status" {
  value = data.cloider_cluster.web.status
}
```

### Configuring the Kubernetes and Helm Providers

```terraform
# In a configuration of its own, deploying into a cluster another one created
data "cloider_cluster" "web" {
  id = var.cluster_id
}

provider "kubernetes" {
  host                   = data.cloider_cluster.web.kube_config.host
  cluster_ca_certificate = data.cloider_cluster.web.kube_config.cluster_ca_certificate
  client_certificate     = data.cloider_cluster.web.kube_config.client_certificate
  client_key             = data.cloider_cluster.web.kube_config.client_key
}

provider "helm" {
  kubernetes = {
    host                   = data.cloider_cluster.web.kube_config.host
    cluster_ca_certificate = data.cloider_cluster.web.kube_config.cluster_ca_certificate
    client_certificate     = data.cloider_cluster.web.kube_config.client_certificate
    client_key             = data.cloider_cluster.web.kube_config.client_key
  }
}
```

### Trusting an Existing Cluster

```terraform
# Lets an existing cluster reach a new database
data "cloider_cluster" "web" {
  name = "web"
}

resource "cloider_database" "orders" {
  name            = "orders"
  engine          = "postgresql"
  trusted_sources = ["cluster:${data.cloider_cluster.web.id}"]
}
```

## Schema

### Optional

- `id` (String) The cluster's id. Set this or `name`.
- `name` (String) The cluster's name. Set this or `id`. Names don't have to be unique, so a name several clusters have is refused, use the `id` then.

### Read-Only

- `created_at` (String) When the cluster was created, RFC 3339.
- `kube_config` (Attributes, Sensitive) How to reach the cluster's Kubernetes api, for the `kubernetes` and `helm` providers. Null until the cluster is ready. (see [below for nested schema](#nestedatt--kube_config))
- `label` (String) The name the dashboard shows.
- `status` (String) `Creating`, `Starting`, `Ready`, `Pausing`, `Paused` or `Terminating`.
- `version` (String) The Kubernetes version.
